## 🚨 What I've Been Shipping

### 📧 ScrubiMail | Email Verification SaaS
Live product under Tradehut Technologies: an email verification API with real-time and bulk checks on a freemium model.
- Django + Django REST Framework API, Celery workers and Redis for bulk verification jobs
- SMTP-level mailbox checks from a dedicated Hetzner server
- KumoMTA for outbound mail, Mailpit for local mail testing

### 🛒 TradeHut | E-Commerce Marketplace ([thetradehut.com](https://thetradehut.com))
- Next.js App Router, Tailwind CSS and Redux
- Mega-menu navigation, faceted product filters and image-based product search
- 15-category catalogue driven by a single shared category config

### 🏢 Enterprise Group | Group Business Portal
- React + TypeScript frontend, Flask backend with secure JWT auth and session management
- Docker Compose with separate staging and production stacks
- NGINX and HAProxy at the edge, horizontally scaled gunicorn backend, Redis on an internal network
- Shipped through CI/CD pipelines

### 📱 Production USSD Service | Ghana
- Django USSD gateway integrating Africa's Talking, Hubtel and Wigal
- HMAC signature verification, circuit breaker and dead-letter queue
- Prometheus metrics, Sentry error tracking and Locust load testing

### 🗣️ Local-Language Voice RAG *(in progress, team project)*
- Self-improving RAG system that speaks Ghanaian local languages, for people who don't speak English
- Mobile-first, built around self-hostable speech models
